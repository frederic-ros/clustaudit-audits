Python runs locally in WebAssembly (Pyodide, with numpy, SciPy and scikit-learn). The first run downloads it once and takes a few seconds. cluster(X, seed, n_clusters=None) returns one integer per row of X; −1 marks a point left unassigned.

    Launch full audit
    Or run the audit on your own machine

    For a method you cannot publish, or to iterate before submitting. Same battery, same scoring, same card.

    git clone https://github.com/frederic-ros/clustaudit-audits.git
cd clustaudit-audits
pip install -r requirements.txt
python -m auditkit check my_method.py
python -m auditkit audit my_method.py --out my_method.audit.json
    After you launch
    1. 1Submit the issueGitHub opens with your name, family and code filled in. Check them and press "Create".
    2. 2A maintainer starts the runOne look at the code, then the label audit launches it. This keeps the free runners for real submissions.
    3. 3The battery runs in isolationYour code runs on 250 datasets in a GitHub Actions job that has no access to the repository. Scoring runs in a separate job that never executes your code.
    4. 4The card is publishedThe issue gets the card as a comment and the link to its page here, with a badge for your README.
